# 🧬 PNCATEHO — ZMK прошивка для скальперского терминала

![Раскладка PNCATEHO](https://github.com/user-attachments/assets/84c0ea27-ba6e-401e-aadf-a2db30b3d987)

Персональная прошивка на базе [ZMK](https://zmk.dev/) для беспроводной клавиатуры на `nice!nano v2` (nRF52840).  
Создана под конкретные задачи «Скальперского терминала» — быстрый ввод торговых команд, переключение окон и работа с функциями.

## 🔧 Аппаратная основа

- **Контроллер:** nice!nano v2 (nRF52840)
- **Shield:** `pncateho`
- **Матрица:** 3 ряда × 4 столбца (10 активных клавиш на левой половине).  
  В keymap-файле `pncateho.keymap` дополнительно присутствуют заглушки `&none` для правой половины / неиспользуемых позиций.
- **Раскладка:** физически соответствует половине сплит‑клавиатуры (левая сторона)

## ⌨️ Слои и назначения

Файл раскладки: `pncateho.keymap`.

### 🔹 Default (слой 0)
Основной слой для навигации и модификаторов.

|       | Col 0 | Col 1 | Col 2 | Col 3 |
|-------|-------|-------|-------|-------|
| Row 0 | LSHFT | P     | LALT  | A     |
| Row 1 | Z     | V     | N     | S     |
| Row 2 |       |       | MO(2) | MO(1) |

- `MO(2)` → переход на **Numbers**
- `MO(1)` → переход на **Other**

### 🔹 Other (слой 1)
Слой для ввода текста и навигации по интерфейсу.

|       | Col 0 | Col 1 | Col 2  | Col 3 |
|-------|-------|-------|--------|-------|
| Row 0 | TAB   | C     | LALT   | W     |
| Row 1 | H     | L     | SPACE  | E     |
| Row 2 |       |       | MO(3)  |       |

- `MO(3)` → переход на **Functions**
- Слой содержит часто используемые буквы и пробел для быстрой печати.

### 🔹 Numbers (слой 2)
Функциональные клавиши, цифры и вспомогательные буквы.

|       | Col 0 | Col 1 | Col 2 | Col 3 |
|-------|-------|-------|-------|-------|
| Row 0 | 1     | 2     | 3     | J     |
| Row 1 | F1    | F2    | F3    | K     |
| Row 2 |       |       |       | X     |

- Используется для ввода числовых параметров, вызова функциональных клавиш, а также быстрых команд `J`, `K`, `X`.

### 🔹 Functions (слой 3)
Редкие системные команды.

|       | Col 0         | Col 1 | Col 2 | Col 3 |
|-------|---------------|-------|-------|-------|
| Row 0 |               |       |       |       |
| Row 1 | `&bootloader` |       |       |       |
| Row 2 |               |       |       |       |

- Удержание клавиши в Row 1, Col 0 переводит контроллер в режим загрузчика (сброс прошивки).

## 💥 Комбо (одновременные нажатия)

На разных слоях работают комбинации клавиш, возвращающие дополнительные символы/модификаторы.  
Для их работы в конфигурации shield'а включена опция `CONFIG_ZMK_COMBO=y`.

| Комбинация              | Результат | Активный слой | Зачем?                          |
|-------------------------|-----------|---------------|----------------------------------|
| `LSHIFT` + `P` + `LALT` | `M`       | Default (0)   | Торговая команда `M`            |
| `Z` + `V`               | `U`       | Default (0)   | Быстрый ввод буквы `U`          |
| `LSHIFT` + `Z`          | `ESC`     | Default (0)   | Выход из режимов/диалогов       |
| `TAB` + `C` + `LALT`    | `LCTRL`   | Other (1)     | Эмуляция Ctrl для горячих клавиш |
| `1` + `2`               | `N4`      | Numbers (2)   | Быстрый ввод цифры 4            |
| `2` + `3`               | `N5`      | Numbers (2)   | Быстрый ввод цифры 5            |
| `3` + `J`               | `Q`       | Numbers (2)   | Специальная команда             |
| `F1` + `F2`             | `F4`      | Numbers (2)   | Быстрый вызов F4                |

> **Важно:** Все комбо привязаны к конкретным слоям, чтобы не мешать обычному набору текста.
